One-time setup in Supabase

Add this exact URL to your project's allowed redirects:

…
  1. Authentication → URL Configuration → Redirect URLs, paste, save.
  2. Authentication → Providers → Google, enable it, and paste the client ID and secret from a Google Cloud OAuth client.
  3. In Google Cloud, that client's authorised redirect URI is https://<project>.supabase.co/auth/v1/callback.
Add the exact URL shown above — this page fills in the right one for this install. Installed from the Chrome Web Store, an extension's identity is the same for every user, so you whitelist it once and every sign-in works against it. Loading the source unpacked instead? The repo pins that identity across your own machines with a key field in manifest.json. A packaged build drops it — the store assigns its own — so an unpacked copy of a package shows a throwaway per-machine ID. Fine for local testing; whitelist whatever it shows. For anyone else, it is the store's URL that counts.
